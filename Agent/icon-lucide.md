# `Icon` renders Lucide; prepare `@mrmeg/expo-ui` 0.26.0

## Goal

`Icon` from `@mrmeg/expo-ui/components/Icon` renders `lucide-react-native` instead of `@expo/vector-icons/Feather`. Lucide is a maintained superset of Feather in the same 24px, 2px-stroke, round-cap style, so nothing changes visually, but consumers stop running out of glyphs (terlo's business taxonomy collapses three food categories onto `coffee`) and the Lucide names its database already stores start resolving. `IconName` becomes a typed union of kebab-case Lucide names served from a registry, the `component` escape hatch stays, the package drops its `@expo/vector-icons` dependency and the icon-font loading that came with it, and the result is published as 0.26.0 so `~/Development/terlo/Agent/look-icons-lucide.md` can unblock.

## Context

Verified on `dev` at `cd53f4b` (package version 0.25.0; the Unreleased changelog already carries "`spacing.radiusMd` is 10 instead of 12", which ships in the same release).

- **Today's `Icon`** (`packages/ui/src/components/Icon.tsx`): `IconName = React.ComponentProps<typeof Feather>["name"]`; props `name | component`, `size` (24), `color` (theme token name or literal, resolved by `resolveIconColor`), `style`, `decorative` (sets the four a11y-hidden props); renders `<Feather … style={[style, { pointerEvents: "none" }]}>`. Exported through `packages/ui/src/components/index.ts` (`export * from "./Icon"`).
- **Internal consumers of `IconName`/`Icon`** (16 files): `Accordion`, `Avatar` (`icon?: IconName`, default `"user"`), `BottomSheet`, `Button`, `Checkbox`, `DropdownMenu` (`chevron-right|chevron-up|chevron-down`), `EmptyState`, `Item`, `Notification`, `Select`, `StatCard` (`DIRECTION_ICON` up/down), `Tabs`, `TextInput`, `Toggle`, `ToggleGroup`, plus tests `__tests__/Icon.test.tsx` and `__tests__/Button.test.tsx`. Names used inside the package: `check`, `x`, `bold`, `mic`, `mic-off`, `heart`, `chevron-down`, `chevron-right`, `terminal`, `minus`, `home`, `calendar`, `box`, `alert-circle`. All but `alert-circle` exist in Lucide under the same name; `alert-circle` is `circle-alert`.
- **Font loading is icon-specific today.** `packages/ui/src/hooks/useResources.ts` imports Feather, primes `Feather.font` at module scope on web, exports `ensureIconFontRegistered()` (registers the font in expo-font's server store during export-time render to avoid hydration error #418), and loads `Feather.font` in the effect. `__tests__/useResources.test.tsx` mocks `@expo/vector-icons/Feather` and asserts the Feather font loads in both override cases. With SVG icons none of this is needed: `react-native-svg` renders `<svg>` on web with no font-face.
- **Tests mock Feather globally.** `test/setup.ts` mocks `@expo/vector-icons` and `@expo/vector-icons/Feather` as `View`s with `testID: "icon-Feather"`; `Icon.test.tsx` finds icons by that testID and asserts a11y props, styles, and color resolution.
- **`lucide-react-native` 1.46.0** (inspected from npm): peers `react` (16.5–19), `react-native` (`*`), `react-native-svg` (`^12 || ^13 || ^14 || ^15`); no dependencies. 1,839 icons. The root entry exports PascalCase components plus legacy aliases (e.g. `export { default as CheckCircle, … as CircleCheckBig } from './icons/circle-check-big.mjs'`), so importing the root would bundle everything. Each icon is also its own subpath: `lucide-react-native/icons/<kebab-name>` with matching `dist/types/icons/<kebab-name>.d.ts`. `LucideProps extends SvgProps` with `size`, `color`, `strokeWidth`, `absoluteStrokeWidth`; `LucideIcon = ForwardRefExoticComponent<LucideProps>`. Default stroke 2 on a 24 viewBox scales with `size`, the same as Feather's glyphs did. There is no kebab-case name→component map export in the RN package.
- **Renames to expect** (Feather → Lucide, verified against the alias table): `check-circle → circle-check-big` (not `circle-check`, which is a different glyph), `x-circle → circle-x`, `alert-circle → circle-alert`, `alert-triangle → triangle-alert`, `help-circle → circle-help`, `more-vertical → ellipsis-vertical`, `more-horizontal → ellipsis`, `edit → square-pen`, `edit-2 → pen`, `edit-3 → pencil`, `sliders → sliders-horizontal`, `grid → layout-grid`. Everything else the generator's check will list; the alias lines in `dist/esm/lucide-react-native.mjs` are the authoritative rename map.
- **The template app** uses `Icon` with about 50 names (`app/`, `client/`; `IconName` is imported by `client/templates/*`, `client/blocks/*`, `client/showcase/*`, `client/features/navigation/navDestinations.ts`, `app/(main)/(tabs)/settings.tsx`, `app/(main)/(demos)/auth-demo.tsx`). `app/(main)/(tabs)/_layout.tsx` imports `@expo/vector-icons/Feather` directly for `NativeTabs.Trigger.VectorIcon family={Feather} name={destination.icon}`; `VectorIcon` needs an icon-font family, so the tab bar keeps Feather. The root `package.json` does not list `@expo/vector-icons` or `react-native-svg` today; Expo SDK 58's pin for `react-native-svg` is `15.15.5` (`node_modules/expo/bundledNativeModules.json`).
- **Gates.** `bun run verify` runs `packages:peer-check`, `typecheck`, `lint`, `check:features`, `gen:templates:check`, `gen:blocks:check`, `docs:llms:check`, `docs:versions:check`, tests. The package's own `bun run ui:release -- --minor` runs `ui:typecheck`, `ui:test`, `ui:build`, `ui:pack`, `ui:consumer-smoke` (`scripts/check-package-consumer.mjs` installs the packed tarball into fixtures and type-checks the public surface) and needs a clean tree. `scripts/check-ui-forbidden-imports.mjs` bans only reanimated/worklets. `scripts/package-compatibility-profiles.mjs` pins peer versions per SDK profile for `packages:peer-check` and `.github/workflows/package-compatibility.yml`. ## Work

Add both to every `ui` profile in `scripts/package-compatibility-profiles.mjs` so `packages:peer-check` and `package-compatibility.yml` pin them per SDK; the consumer-smoke fixture in `scripts/check-package-consumer.mjs` already spreads `peerDependencies` into its install, so it picks them up unchanged.
